IMAGE REPLACEMENT GUIDE

Place approved replacement photos inside assets/projects/.

Example:
assets/projects/facade-main.jpg

Then edit content.js and change the relevant image field to:
image: "assets/projects/facade-main.jpg"

Available fields:
- hero.image
- hero.insetImage
- aboutImage
- projects[].image

To remove a project:
- Set visible: false, or
- Delete that project object from the projects array.

The current project photos are temporary references to the original public website repository. The final replacement images can be stored locally in this repository.
